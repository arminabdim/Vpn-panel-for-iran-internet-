# اوپن‌پت (OpenPath)

**یک پنل رایگان برای ساخت کانفیگ‌های واقعی برای ایران — بدون سرور، بدون هزینه، بدون شرکت واسطه.**

اوپن‌پت مجموعه‌ای از «تولیدکننده و رله» است که کاملاً روی زیرساخت رایگان اجرا
می‌شود: پلن رایگان کلودفلر، سهمیه‌ی رایگان Apps Script حساب گوگل خودتان،
هاست‌های کانتینری رایگان، و برای روزهای سخت، یک دورزننده‌ی فیلترینگ (DPI) که روی
خود گوشی یا لپ‌تاپ اجرا می‌شود. ایده از
[BPB-Worker-Panel](https://github.com/bia-pain-bache/BPB-Worker-Panel) و
[MasterHttpRelayVPN](https://github.com/masterking32/MasterHttpRelayVPN) گرفته
شده، اما **به پنل شخص دیگری وابسته نیستید**: گره را خودتان می‌سازید، پس وقتی
پنل‌های دیگر فیلتر می‌شوند این یکی کار می‌کند.

> این یک سرویس VPN نیست. اوپن‌پت چیزی به شما نمی‌فروشد و ترافیک شما را نمی‌بیند؛
> فقط ابزار ساخت اتصال خودتان را می‌دهد. لطفاً مسئولانه و مطابق قانون استفاده کنید.

## یک دستور (ترموکس / اندروید)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/arminabdim/Vpn-panel-for-iran-internet-/main/install.sh)
```

همین. فقط `python3` و `git` لازم دارد (در ترموکس: `pkg install python git`)،
در پوشه‌ی `~/openpath` نصب می‌شود و پنل را در مرورگرتان روی
`http://127.0.0.1:8765` باز می‌کند. بعد از آن همه چیز با کلیک است.

روی کامپیوتر:

```bash
git clone https://github.com/arminabdim/Vpn-panel-for-iran-internet-.git
cd Vpn-panel-for-iran-internet-
python3 openpath.py panel
```

اگر اصلاً چیزی نصب نمی‌کنید، همان پوشه‌ی `panel/` را با هر سرور استاتیک (یا
GitHub Pages) باز کنید: پنل در **حالت مستقل** کار می‌کند — ساخت کانفیگ، کیوآر،
قالب‌ها و همه‌ی راهنماها. فقط دکمه‌هایی که به برنامه‌ی کمکی روی دستگاه نیاز
دارند (نصب ورکر، تست سرعت) غیرفعال می‌شوند.

## داخل پروژه چه هست؟

| بخش | کارش | نیاز |
|---|---|---|
| **پنل** (`panel/`) | یک رابط گرافیکی واقعی: ۱۸ روشِ مستند، سازنده‌ی کانفیگ، کیوآر، تست تاخیر و راهنما. بدون اینترنت هم کار می‌کند. | یک مرورگر |
| **موتور** (`openpath/core/configs.py` + `panel/assets/js/engine.js`) | یک لینک می‌گیرد و برای VLESS / VMess / Trojan / Shadowsocks / Hysteria2 / TUIC / WireGuard خروجی می‌دهد: لینک، sing-box، Clash، Xray یا سابسکریپشن base64. نسخه‌ی پایتون و جاوااسکریپت **خروجی کاملاً یکسان** دارند (۵۰ خروجی که در CI مقایسه می‌شود). | — |
| **ورکر کلودفلر** (`worker/`) | گره شخصی VLESS/Trojan روی `*.workers.dev`، مستقیم از پنل و فقط با یک توکن — بدون wrangler و بدون Node. | حساب رایگان کلودفلر |
| **WARP** (`openpath/core/warp.py`) | ساخت حساب WireGuard وارپ با پایتون خالص (بدون wgcf) و تحویل کانفیگ با IPهای تمیز کلودفلر. | — |
| **رله‌ی گوگل** (`gas/Code.gs`) | یک رله‌ی HTTP/SOCKS5 که داخل Apps Script زندگی می‌کند. در قطعی‌های نزدیک‌به‌کامل ایران، این **آخرین چیزی بوده که هنوز کار می‌کرد**. | یک حساب گوگل |
| **دور زدن فیلترینگ** (`openpath/core/dpi.py`) | شکستن رکورد TLS به قطعات کوچک همراه با یک ClientHello فریبنده، **به همراه یک مسیر جایگزین**: اگر اتصال به‌خاطر همین شکستن قطع شود، همان درخواست بدون شکستن دوباره فرستاده می‌شود تا سایتی از دسترس خارج نشود. | خود دستگاه |
| **PaaS** (`paas/`) | یک Dockerfile که یک سرویس رایگان Render یا Codespace را به گره‌ی Hysteria2 / TUIC / Shadowsocks تبدیل می‌کند — پروتکل‌هایی که ورکر نمی‌تواند اجرا کند. | هاست کانتینری رایگان |
| **ابزار سابسکریپشن** (`openpath/core/sub.py`) | جمع‌آوری کانفیگ‌های عمومی، حذف تکراری، تست تاخیر و خروجی برای هر کلاینت. | اینترنت |

### ۱۸ روش

ورکر کلودفلر · صفحات کلودفلر · CF Snippets · رله‌ی CF · وارپ · رله‌ی Apps Script گوگل ·
DPI داخلی · SpoofDPI · ByeDPI · Xray fragment · Render · Codespaces · Deno ·
DNSTT/SlipNet · پل‌های Tor · سابسکریپشن‌های عمومی · MTProto · (بخش آزمایشی)

هر کدام در پنل با **وضعیت، سختی، هزینه، زمان استفاده، محدودیت‌ها و مراحل
قدم‌به‌قدم** توضیح داده شده — به انگلیسی و فارسی.

## رسیدن به یک کانفیگِ کار در ۵ دقیقه

**راه اول — گره شخصی کلودفلر (توصیه‌شده، ماندگارترین)**

۱. در [dash.cloudflare.com](https://dash.cloudflare.com) ثبت‌نام کنید (رایگان).
۲. ساخت توکن: *My Profile ← API Tokens ← Create Custom Token* با دسترسی‌های
   `Workers Scripts: Edit` و `Account Settings: Read`.
۳. در پنل: تب **Worker** ← توکن را بچسبانید ← **Deploy**.
۴. لینک سابسکریپشن را در **v2rayNG** یا **MahsaNG** وارد کنید.

**راه دوم — بدون ثبت‌نام**

پنل ← **Methods** ← *رله‌ی Google Apps Script* (یا *WARP*) و مراحل را بروید.
در تب WARP بدون هیچ حسابی کانفیگ WireGuard ساخته می‌شود.

**راه سوم — وقتی همه چیز فیلتر است**

پنل ← تب **DPI** ← Start. بعد پروکسی سیستم یا برنامه را روی
`127.0.0.1:8081` (HTTP) یا `1081` (SOCKS) بگذارید.

---

## کلاینت‌ها

* **v2rayNG / MahsaNG (اندروید)** — لینک سابسکریپشن پنل را وارد کنید؛ هر دو
  سابسکریپشن، YAML کلش و لینک تکی را می‌فهمند. برای Hysteria2 و TUIC باید
  **MahsaNG** یا هر کلاینت sing-box داشته باشید (v2rayNG آن‌ها را اجرا نمی‌کند).
* **sing-box / Hiddify / Nekobox / Clash** — همان لینک را بدهید یا JSON تولیدشده
  را وارد کنید.
* **کامپیوتر** — تب **Test** پنل قبل از انتخاب، تاخیر و سرعت را اندازه می‌گیرد.

## خط فرمان

```bash
python3 openpath.py                 # منوی تعاملی
python3 openpath.py panel           # باز کردن پنل
python3 openpath.py cf deploy       # ساخت و نصب ورکر کلودفلر
python3 openpath.py warp new        # ساخت کانفیگ‌های وارپ
python3 openpath.py gas new         # چاپ رله‌ی Apps Script
python3 openpath.py dpi start       # دورزننده محلی روی پورت 8081
python3 openpath.py sub fetch       # جمع‌آوری و تست کانفیگ‌های عمومی
python3 openpath.py test            # تست تاخیر و TLS
python3 openpath.py doctor          # همین الان روی این شبکه چه چیزی کار می‌کند؟
python3 openpath.py selftest        # ۴۶ بررسی آفلاین
python3 openpath.py help            # فهرست دستورها
```

## بررسی صحت

```bash
python3 openpath.py selftest           # → 46 passed, 0 failed  (بدون اینترنت)
python3 tools/crosscheck.py            # → تطابق کامل موتور پایتون و جاوااسکریپت
node tools/worker_runtime_test.mjs     # → 12 passed  (ورکر واقعاً کانفیگ می‌دهد)
npm install jsdom && node tools/panel_test.cjs   # → 57 passed  (پنل، هر دو حالت)
python3 tools/pages_build.py           # → ساخت سایت، بدون وابستگی خارجی
```

همه‌ی این‌ها روی هر push در CI اجرا می‌شوند (`.github/workflows/test.yml`).

## چند نکته‌ی ایمنی

* همه چیز روی دستگاه خودتان است: نه telemetry، نه آنالیتیکس، نه اسکریپت خارجی،
  نه فونت یا CDN شخص ثالث در پنل.
* **کانفیگ عمومی** یعنی کامپیوترِ یک غریبه. فقط برای وب‌گردی؛ هرگز برای بانک و
  رمز عبور. برای کارهای حساس، گره شخصی خودتان را بسازید.
* پلن رایگان کلودفلر روزانه ۱۰۰٬۰۰۰ درخواست اجازه می‌دهد؛ پنل هشدار می‌دهد و
  وارپ یا رله را پیشنهاد می‌کند.
